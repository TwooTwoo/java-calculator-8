# java-calculator-precourse

## 구현 기능 목록
- [x] 사용자가 문자열을 입력 가능하도록 함
- [x] 사용자가 입력한 문자열이 비어있는지 검증
- [x] 사용자가 입력한 문자열이 비어있다면 결과: 0을 출력
- [x] 사용자가 입력한 문자열에서 커스텀 구분자가 사용되었는지 확인
- [x] 사용자가 입력한 문자열을 "커스텀 구분자를 지정하는 부분(이하 부분1)"과 "숫자+구분자를 입력한 부분(이하 부분2)"으로 분리
- [x] 커스텀 구분자가 사용되었다면 기본 구분자 + 커스텀 구분자로 부분2를 분리
- [x] 커스텀 구분자가 사용되지 않았다면 기본 구분자로 부분2를 분리
- [x] 분리된 문자들을 숫자로 파싱해 배열에 저장
- [x] 배열에 저장된 숫자들의 합 구하기
- [] 배열의 저장된 숫자들의 합 출력

## 커밋 메세지 형식 정리
- **feat (feature)** : 새로운 기능 추가
- **fix (bug fix)** : 버그 수정
- **docs (documentation)** : 문서 수정
- **style (formatting...)** : 코드 포맷팅(공백, 세미콜론 등 논리 변화 없음)
- **refactor** : 코드 리팩토링(기능 변화 없음)
- **test** : 테스크 코드 추가 수정
- **chore (maintain)** : 빌드, 설정 등 유지보수성 변경 (코드 로직과 무관)
